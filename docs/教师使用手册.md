# 教师使用手册

本手册面向初中数学教师，介绍平台教师端的完整使用流程：班级管理 → 复制模板 → 编辑任务单 → 配置 AI → 发布任务 → 批阅与成果分析。

教师登录入口：`/login/teacher`。演示账号 `teacher / 123456`（张老师）。

---

## 一、核心概念：官方模板 vs 教师任务单副本

| | 官方模板 | 教师任务单副本 |
| --- | --- | --- |
| 位置 | 模板库 | 我的任务单 |
| 是否可改 | **不可修改**（只读） | 完全可编辑 |
| 来源 | 平台团队预置（10 份：数与代数 4、图形与几何 3、统计与概率 3） | 由模板复制生成，或教师新建空白任务单 |
| 归属 | 全体教师共享 | 仅创建者本人可见、可发布 |

复制是**深拷贝**：模板的文字、步骤、评价标准、参考范例都会被复制到副本，之后对副本的修改不会影响模板，其他教师的副本也不受影响。

---

## 二、工作台

登录后进入 `/teacher`，可看到：

- 我的班级数、我的任务单数、已发布任务数、学生提交数；
- 快捷入口：班级管理、模板库、我的任务单。

---

## 三、班级管理

### 1. 新建班级

1. 左侧导航进入「班级管理」；
2. 点击右上角「新建班级」；
3. 填写班级名称（如“八年级(1)班”）与年级；
4. 点击「创建班级」，自动进入班级详情页。

### 2. 添加单个学生

在班级详情页点击「添加学生」，填写：

- 用户名（全局唯一，支持中文、字母与数字，如“李小明”或“lixm01”）；
- 姓名；
- 初始密码（至少 6 位，默认 `123456`）。

若该用户名已是学生账号，系统会直接把该学生加入班级，无需重复设置密码。

> 学生账号只能由教师创建；学生端没有自助注册入口。

### 3. 批量导入名单（Excel）

1. 点击「批量导入」→「下载 Excel 模板」，得到 `班级名-学生导入模板.xlsx`；
2. 用 Excel / WPS 打开，按三列填写（表头不要改）：

| 用户名 | 姓名 | 初始密码 |
| --- | --- | --- |
| zhangsan01 | 张三 | 123456 |
| lisi02 | 李四 | 123456 |

3. 保存文件，回到页面选择该 Excel（支持 `.xlsx / .xls / .csv`），点击「开始导入」；
4. 页面提示新建账号数、加入班级数与跳过原因（如学号重复、密码不足 6 位）。已有学生账号会直接加入班级，不会重复创建。

> 不支持直接粘贴文本，必须使用 Excel 模板文件，避免格式错位。

### 4. 导出名单

点击「导出名单」下载当前班级学生名单 Excel（`.xlsx`）。

### 5. 移出学生

在学生名单中点击「移出班级」。**只解除班级关系，学生账号仍保留**，可再加入其他班级。

---

## 四、从模板创建任务单

1. 进入「模板库」，可按「数与代数 / 图形与几何 / 统计与概率」筛选；
2. 每张模板卡片展示标题、适用年级、项目类型、学习目标摘要；
3. 点击「复制并编辑」→ 系统生成《模板标题（副本）》并跳转任务编辑器；
4. 模板卡片本身没有编辑入口，因此原始模板不会被误改。

### 新建空白任务单

进入「我的任务单」，点击「新建任务单」，填写标题、选择数学板块，即可从零开始编辑。

---

## 五、编辑任务单

编辑器左侧为内容区，右侧为 AI 与发布面板。可编辑字段：

| 区域 | 说明 |
| --- | --- |
| 基础信息 | 标题、数学板块、项目类型、适用年级、建议课时、任务简介、封面图 |
| 项目背景 | 真实情境与数据，学生端以段落呈现 |
| 涉及知识 | 逗号或换行分隔，学生端显示为知识标签 |
| 学习目标 | 逐条添加/删除，建议使用可观察、可评价的行为动词 |
| 任务描述 | 驱动问题与最终成果要求 |
| 实施步骤 | 项目整体流程，每步含名称与做法 |
| 项目进程 | 3 个左右阶段，每阶段含任务清单、学生填写表格的列、作答提示；可嵌入交互工具（如漏水估算器） |
| 评价标准 | 教师评分维度，含名称、权重（%）、表现描述 |
| 自我评价量表 | 4–6 个维度，每个维度填写 A/B/C/D 四级表现，学生端自动生成自评表 |
| 总结与反思提示 | 每行一条，学生端生成对应反思输入框 |
| 配套参考范例 | 范例标题、文字说明、图片（可多图） |

编辑框均可拖拽右下角调整高度，任务描述、项目背景、参考范例等大段内容已默认加高。编辑完成后点击「保存任务单」，**未保存直接离开会丢失修改**。

> 原始模板不需要也不允许逐字抄写；参考内置的“珍惜水资源”模板即可看到完整的信息量标准。

> 图片上传单文件不超过 20MB，支持 jpg/png/gif/webp 等常见图片格式；学生成果附件支持图片与文档。

## 六、AI 辅助配置（每份任务单独立）

右侧「AI 辅助能力」卡片：

1. **开关**：控制这份任务单是否向学生开放 AI 侧栏。关闭后学生端显示“教师尚未开启”；
2. **工具库（专题页）**：顶部导航「交互探究工具库」可查看全部工具、按类型与板块筛选、点击「立即预览」在弹窗中直接试用，也可在该页上传自己的 HTML 教具（永久保存在服务器，可在任意任务单中勾选）。内置工具分两类：
   - **交互探究教具**：动态几何画板（拖动顶点看边长/角度/面积）、函数图像探究（拖动 k、b、a 滑块）、概率模拟实验（抛硬币/掷骰子观察频率）、统计图表探究（切换条形图/扇形图/折线图）；
   - **辅助工具**：漏水水量估算器、问卷设计助手、数据梳理与图表、建模思路拆解、几何猜想记录板、结论表达引导、过程检查清单；
   工具内点“写入我的作答”会把结果追加到学生成果概述；
3. **在任务单中勾选工具**：编辑器「工具库」按同样两类展示，勾选后保存即可生效；
4. **AI 成果评价 / 思考提示**：每份任务单自带，学生可获取建议分、维度得分、改进点与阶段思考提示；
5. 修改后点击「保存AI设置」生效；任务单内容变化后，推荐能力会随之更新。

> 工具编写约定：需要回写结果时，请使用平台传入的父页面来源作为目标：
> `window.parent.postMessage({ type: 'pbl-append', text: '要写入的内容' }, 目标来源)`，
> 目标来源取自 URL 参数 `parentOrigin`（平台会自动附加并校验消息来源），不要写死为 `'*'`。
> 当前评价为规则版，教师可在批阅页一键采纳建议分与评语；第二迭代可替换为大模型 API。

---

## 七、发布与撤回

在编辑器右侧「发布到班级」：

1. 选择班级（显示人数）；
2. 可选填写截止日期；
3. 点击「发布任务」。同一任务对同一班级重复发布会更新原发布记录，不会产生重复作业；
4. 发布后列表显示「已发布」、提交进度（如 `2/4 份提交`）与截止日期；
5. 点击「查看提交」进入批阅页；点击「撤回」可撤回。

撤回后学生端不再显示该任务，已提交的成果仍保留在教师批阅页中，可再次发布。

> 发布前请先保存任务单；发布的是“当前已保存版本”。

---

## 八、批阅与评价

进入批阅页（也可从班级详情页的「班级任务 → 批阅」进入）：

1. 左侧为学生提交情况列表，状态分为「待批阅」「已批阅 xx 分」「未提交」；
2. 点击学生查看其分阶段作答、表格数据、自评、反思与附件，以及平台 AI 成果评价；
3. 可点击「采纳建议分与评语」把 AI 建议填入右侧表单，再按课堂表现修改；
4. 填写分数（0–100）与评语，点击「保存批阅」。保存后学生端立即可见；已批阅的成果学生不能再修改；
5. 页面顶部「班级分析报告」可直接查看该任务的班级报告。

---

## 九、成果分析报告

在班级详情页底部「成果分析报告」：

1. 下拉选择一项已发布任务；
2. 点击「生成分析」。

报告包含：

- 班级人数、提交人数与提交率、平均分、已批阅情况；
- 分数段分布（可视化条形）；
- 各评价维度均分；
- 共性亮点与共性问题（依据评价标准与提交内容自动归纳）；
- 学生个人明细（分数、维度得分、字数/附件情况、改进建议）。

> 当前分析为规则版（字数、段落、附件、评价维度加权等），第二迭代将替换为大模型分析。

---

## 十、数据隔离与安全

- 每份任务单、班级、发布记录都绑定创建教师；**其他教师无法看到或操作你的数据**（访问返回 404）；
- 官方模板与教师副本分表存储，模板无写接口；
- 密码使用 scrypt 加盐哈希存储，登录后签发 7 天有效期 Token；
- 删除任务单前请确认：**已有学生提交的任务不可删除**，需先撤回并处理提交。

## 十一、常见问题

**Q1：为什么模板库没有“编辑”按钮？**
官方模板只读，需要先「复制并编辑」生成自己的副本，这是平台的模板保护机制。

**Q2：学生的账号密码忘了怎么办？**
当前版本暂不支持教师重置密码，可在班级中移除后重新添加（用户名相同会复用原账号，但需数据库层面处理）。演示阶段建议统一使用初始密码 `123456`，后续迭代会加入密码重置功能。

**Q3：发布了任务，学生却看不到？**
依次检查：① 任务已保存并发布到该学生所在班级；② 发布状态为「已发布」而非「已撤回」；③ 学生登录的是学生端入口。

**Q4：AI 侧栏里没有内容？**
确认这份任务单的 AI 开关已开启并点击了「保存AI设置」；若任务单内容过少，推荐能力可能较少，补充任务描述与步骤后重新保存即可。

**Q5：能否一份任务单发布给多个班级？**
可以。在「发布到班级」中逐个选择班级发布，每个班级会生成独立的发布记录与批阅入口。
