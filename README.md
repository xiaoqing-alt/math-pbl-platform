# 数创工坊 · 初中数学项目式学习平台（大创原型 v1）

面向初中数学教师与学生的项目式学习（PBL）数字化平台，围绕**数与代数、图形与几何、统计与概率**三大板块，以**任务单**为核心载体。当前版本已完成基础业务闭环：模板复制、副本编辑、班级管理、发布任务、学生提交、教师批阅、成果分析，并内置**规则版 AI 辅助侧栏**（第二迭代接入大模型 API）。

## 功能一览

| 模块 | 已实现能力 |
| --- | --- |
| 官方模板库 | 10 份预设模板（数与代数 4、图形与几何 3、统计与概率 3），只读，无任何写接口；含完整的项目背景、项目进程、自评量表与参考范例 |
| 任务单实例 | 复制模板生成独立副本 / 新建空白任务单；可编辑背景、目标、知识标签、驱动问题、实施步骤、分阶段任务（含学生填写表格列）、四级自评量表、反思提示、评价标准、参考范例 |
| 班级管理 | 创建班级、添加/移除学生、下载 Excel 模板填写后上传批量导入、导出名单 Excel |
| 发布与撤回 | 任务单发布到指定班级、撤回已发布任务 |
| 学生端 | 阅读完整任务单，按阶段填写表格与作答、完成四级自评、写总结反思、上传附件、查看评分与评语 |
| 教师批阅 | 查看分阶段作答与附件、AI 预评、打分、写评语、查看班级分析报告 |
| AI 辅助 | 每份任务单独立开关；**工具库**含 4 个交互探究教具（动态几何画板、函数图像探究、概率模拟实验、统计图表探究）与 7 个辅助工具；教师可勾选使用或上传自己的 HTML 教具；学生侧栏沙箱加载，结果可一键写回作答；并提供 AI 成果评价 |
| 成果分析 | 规则版自动分析（阶段完成度、表格数据、字数/附件、维度得分、亮点与改进），生成班级报告 |

## 技术栈

- 前端：React 18 + React Router 6 + Vite 5 + TypeScript，响应式适配电脑/平板
- 后端：Node.js（>= 22.5）+ Express 4 + `node:sqlite`（零原生依赖）
- 鉴权：scrypt 密码哈希 + HMAC-SHA256 签名 Token（7 天）
- 文件：multer 单文件上传（20MB，扩展名白名单），静态托管于 `/uploads`
- 部署：单服务模式（后端托管前端 `dist`）；或 GitHub Pages（静态前端）+ 独立后端

## 快速开始

要求 **Node.js >= 22.5**（`node:sqlite` 依赖）。

```bash
npm install
npm run seed        # 初始化官方模板与演示账号（幂等）
npm start           # 启动 http://localhost:3001（自动托管 client/dist）
```

前后端分离开发模式：

```bash
npm run build       # 构建前端（首次需执行）
npm run dev:server  # 后端 3001
npm run dev:client  # 前端 5173，已代理 /api 与 /uploads
```

演示账号：

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 教师（张老师） | `teacher` | `123456` |
| 学生（李小明等 4 人） | `student` / `s2` / `s3` / `s4` | `123456` |

演示班级：八年级(1)班。学生账号由教师在班级管理中创建，学生端不开放自助注册。

## 数据与安全说明

- 原始模板存于 `templates` 表且**只读**；教师副本存于 `tasks` 表并记录 `template_id` 来源，互不影响。
- 教师只能访问自己名下的任务单、班级与作业；跨教师访问返回 404。学生只能看到自己所在班级已发布的任务。
- 演示数据位于 `server/data/`（SQLite 数据库与鉴权密钥），上传文件位于 `server/uploads/`，已被 `.gitignore` 忽略。重置演示数据：删除这两个目录后执行 `npm run seed`。

## 迭代规划
